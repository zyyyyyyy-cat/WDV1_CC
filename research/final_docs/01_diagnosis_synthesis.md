# WHU / UAD 历史实验失败机理综合诊断

> 证据来源：`01_UAD_WHU_Analysis.md`、`02_Previous_Experiments.md`、`05_Results.csv`、`research/phase1_logs/log_trajectory_report.md`、`research/phase1_history/audit_group1*.md`、`audit_group2*.md`、A-V1/B-B/WCV1 代码与诊断、以及本轮离线特征实验。

## 0. 结论先行

历史 17 组方法、最新 A-V1/B-B/WCV1，以及本轮 6 类免训练后处理实验，共同指向同一个结论：

> **UAD 的瓶颈不是“缺少某个模块/损失”，而是训练动力学与开放集度量几何。**
> 继续在共享 CLS 上叠加排序/对比/模态原型损失，会系统性抬高最危险负样本，伤害 Rank-1；任何全局特征后处理（中心化、白化、CORAL、LDA、分数校准）都会破坏已有度量；真正未被尝试且证据支持的方向是 **延长并稳定优化、修正训练-检索几何错配、提升原型可靠性、推理期轻量增强**。

## 1. 为什么 mAP 微降而 Rank 大幅下降

### 1.1 指标定义决定了两者不可互代

- mAP 是逐 query AP 的宏平均；AP 取决于**所有正样本**的排名位置，而不是只看第一名。
- Rank-1 是 top-1 是否命中；Rank-5/10 是首个正样本是否进入前 5/10。
- 一个方法可以改善“正样本整体位置/覆盖”（mAP↑），同时破坏“第一名边界”（R1↓）。[C]

### 1.2 顶部边界极脆弱

- 本轮离线实验：对同一批 UAD 特征，用 raw 欧氏距离与 L2 余弦距离检索，**R1 相同（27.0% vs 27.0%，1000 抽样）**，但 **top-1 仅 65.8% 一致**。[R]
- 特征范数均值≈10、std≈0.38，说明不是范数主导；大量候选分数接近，微小扰动即可互换 top-1。
- 这解释了为什么模块常出现“mAP 小变、R1 大幅互换”：A-V1 的 Rank-1 有 **472 个新失败、340 个新成功**，净 −132；Rank-5/10 也各有约 470/340 的双向转变。[R]

### 1.3 失败与成功的 AP 贡献不对称

A-V1 的 ΔAP 分解（相对 UAD）[R]：

| Rank-1 组别 | Query 数 | 组内平均 ΔAP | 对总体 ΔmAP 贡献 |
|---|---:|---:|---:|
| 两者都命中 | 1431 | −0.008916 | −0.1992 pp |
| 新失败 | 472 | −0.047120 | −0.3472 pp |
| 新成功 | 340 | +0.035838 | +0.1902 pp |
| 两者都失败 | 4162 | −0.000985 | −0.0640 pp |
| 合计 | 6405 | — | −0.4202 pp |

- R1 净 −2.06pp，但 mAP 只 −0.42pp，因为新失败的 AP 损失被新成功的 AP 增益抵消了一部分。
- 1431 个“R1 保持正确”的 query 仍合计贡献 −0.1992pp，说明**头名没变错，后续正样本排序也可能变差**。[R]
- 472 个新失败中 354 个（75%）仍在前五、420 个（89%）仍在前十；只有 52 个连 Rank-10 也丢失。[R]

### 1.4 正侧与负侧的不对称

A-V1 的 472 个 R1 新失败中 [R]：

| 最近邻变化 | Query 数 | 比例 |
|---|---:|---:|
| 最佳正样本下降 + 最危险负样本上升 | 196 | 41.5% |
| 最佳正样本下降、负样本未上升 | 9 | 1.9% |
| 正样本未下降、负样本上升 | 267 | 56.6% |

- **463/472（98.1%）的新失败伴随最危险负样本相似度上升**；只有 205/472（43.4%）伴随最佳正样本下降。
- 平均 Δs+ = +0.00575，Δs− = +0.05859，margin 从 +0.02259 变成 −0.03026。
- 全体 query 的最佳正样本、最危险负样本平均相似度都上升（+0.02909、+0.03911），但负侧上升更快，margin 下降。
- 全体负图像对的平均相似度反而略降，但**99 分位**上升；每 query 取最大时，少数高尾负样本决定 top-1。[R]

**结论**：mAP 微降 + Rank 大跌的直接机制是 **最危险负样本被推近**，而不是正样本全面变差；这与“新增排序/对比损失”高度相关。

### 1.5 mINP 与 R1 也可分化

- HiHR 同模态 mINP 上升而 R1 下降；WQVD A1 融合特征 mINP 相对 UAD 上升但 R1 下降；WCV1 mINP 0.724 vs UAD 0.660，R1 却 −1.33pp。[R]
- mINP 关注“最后一个正样本”的位置，R1 关注第一个；两者对排序的不同部分敏感，不能互相替代。
- 因此“mAP/R1/R5/R10/mINP 全指标 +1”必须同时优化头部边界和尾部覆盖，不能靠单一损失。

## 2. 为什么九种模态组合的规律与总体不一致

### 2.1 总体不是九组合的平均

- 总体 AS-ReID 是 3 模态 query × 3 模态 gallery 的混合候选；九组合各自只面对 1/3 gallery。[C]
- 1000 基线九组合 mAP 等权平均 12.29%，总体 mAP 11.02%；九组合 R1 平均 19.12%，总体 R1 29.71%。[R]
- 一个 query 的 top-1 可以来自任一 gallery 模态，因此总体 R1 是九组合的“并集”，边际收益次线性；单对 R1 +1pp 只带来总体约 +0.28–0.29pp（1000）。[R]

### 2.2 模态难度差异

1000 基线九组合（mAP/R1）[R]：

| 方向 | mAP | R1 |
|---|---:|---:|
| RGB→RGB | 26.53 | 42.48 |
| RGB→NIR | 16.07 | 27.17 |
| RGB→TIR | 5.61 | 7.49 |
| NIR→RGB | 15.66 | 24.54 |
| NIR→NIR | 16.83 | 27.96 |
| NIR→TIR | 5.25 | 6.37 |
| TIR→RGB | 5.85 | 7.40 |
| TIR→NIR | 5.25 | 7.92 |
| TIR→TIR | 13.52 | 20.75 |

- TIR 作为 query 或 gallery 的方向普遍弱；TIR→TIR 也弱于 RGB→RGB/NIR→NIR，说明 TIR **模态内表征**不足，不只是跨模态对齐问题。[R]
- TIR 相关五对占 1000 总体 mAP 权重 55.6%（每对 1/9，TIR query 3 对 + TIR gallery 3 对 − TIR→TIR 重复 1 对）。[R]
- 2337 的 TIR 更少，TIR→TIR 单对权重降至 0.0843，但 TIR 相关五对仍占 49.7%。[R]

### 2.3 混合 gallery 的竞争

A-V1 诊断 [R]：

- 472 个 Mixed Rank-1 新失败中，错误 top-1 来自同模态的 272 个（57.6%），跨模态 200 个（42.4%）。
- 189/472（40.0%）在至少一个单模态 gallery 内仍是 Rank-1 正确，却在 Mixed 中输给其他模态的错误头名。
- 这说明问题同时包含 **模态内身份判别下降** 与 **跨模态分数竞争**；不能只归因于跨模态对齐。

### 2.4 平台维度的差异大于模态

UAD 特征场景质心余弦 [R]：

| 场景对 | 余弦 |
|---|---:|
| RGB-G ↔ NIR-G | 0.954 |
| RGB-G ↔ TIR-G | 0.927 |
| RGB-G ↔ RGB-A | 0.388 |
| NIR-G ↔ NIR-A | 0.433 |
| TIR-G ↔ TIR-A | 0.445 |

- **Ground/Aerial 的平台差异远大于 RGB/NIR/TIR 的模态差异**。
- UAD 的 ProCA 只按模态求中心，不按平台；GPD 每个身份一个原型，也不区分平台。[C]
- 这解释了 AG-ReID 的方向不对称、平台混合中心的噪声，以及“模态指标变化与组合不一致”的一部分原因：同一模态中心混合了 ground/aerial 两个子分布。[H]

### 2.5 训练采样与评测候选不一致

- 评测排除**所有同相机 gallery**（包括同相机异身份负样本、同相机同身份正样本）。[C]
- 训练 WRT 只按 PID 分正负，不区分相机；同相机异身份仍作为负样本，同相机同身份仍作为正样本。[C]
- 这构成两层目标分布错配：训练花容量分离评测中不出现的同相机负样本；训练拉近评测中不出现的同相机正样本。[H]
- 影响大小未测，但这是一个与数据集规模无关的潜在瓶颈。

## 3. 为什么大量模块没有实现预设功能

### 3.1 终端路径/空路径

| 实验 | 代码事实 | 后果 |
|---|---|---|
| PEFT DPA | 最后一层 DPA 只写 Patch；最终只取 CLS，且无 Patch 损失 | 最后一层 DPA 梯度恒零，检索不可见 [C] |
| ViSA | 融合 WRT 对 shared 分支 detach；测试距离固定含 20% local | shared 80% 分量未直接适配最终距离；local 弱信息进入距离 [C] |
| PAT | Part token 与 CLS 在 attention mask 中断开；测试只用 CLS | 局部监督强，但最终 CLS 不直接保留 Part 信息 [C] |
| TAUR | rank loss 梯度只回 TIR Adapter，不回主干；日志占比 1.5–2.1% | 附加监督对共享几何影响极小 [C][R] |
| WQVD A1 | 主损失只监督 z=c+0.05u，局部 CE 只训 u | local 分支的收益需经固定残差传递，传递效率低 [C] |
| ICRE | gamma 0.01→0.436，残差比 25–28% | 初始 1% 的安全约束没有保持，实际是全 Patch 强改写 [C][R] |

**教训**：必须逐层追踪“新增输出 → 最终 CLS → 检索距离”的终端路径；参数非零、损失非零、梯度非零都不等于对检索有贡献。

### 3.2 数值 dead / 饱和 / 轴错配

| 实验 | 代码事实 | 后果 |
|---|---|---|
| SCSR v3 | 零 init + 小梯度 + WD，残差/Patch ≈ 3e-8，gate ≈ 2.2e-5；ON/OFF 完全相同 | 模块数值 dead，等于没加 [C][R] |
| PAT CSL | 未归一化点积、τ=0.1，top logit≈992，CSL loss≈0；邻居 96.4% 同 ID、92.7% 同相机 | 损失饱和；邻居选择与评测候选严重不一致 [C] |
| M-SpecGene | 源 pos_embed 是 W-major 2D sincos；转换器按 H-major 插值到 (16,8)，cos 0.818、相对误差 55.8% | 位置编码确定错配；全模态灾难下降 [C] |
| RLE | NIR/TIR 是 convert('RGB') 三通道复制图；独立通道 RRLE 制造伪彩色；RGB 先 MRLE 再 RRLE | RGB 自检索降幅最大；E2 关 TIR 仍退化 [C][R] |

**教训**：模块“能跑、损失下降、梯度非零”不代表有效；要检查数值幅度、饱和、位置编码、输入通道语义、归一化顺序。

### 3.3 监督对象 ≠ 推理特征

- CE 在 BNNeck 后特征上；WRT/ProCA/GPD 在 BN 前特征上；推理用 L2 归一化的 BN 前 CLS。[C]
- 新增分支常监督自己的私有特征/头（HNSM 关系头、PAT Part 头、WQVD local CE、TAUR adapter），这些头不参与推理。
- 私有头可以吸收辅助任务，使主损失下降但最终 CLS 排序不变。[H]
- WQVD A1 的诊断：A1-CLS 相对 UAD R1 −1.50，融合只补回 +0.92，仍低于 UAD；同权重融合 ON>OFF 不等于整体优于独立 UAD。[R]

### 3.4 新增参数/优化配置不匹配

- 历史新增模块普遍沿用 backbone 的 LR/WD；只有 TAUR Adapter 用 3× LR，但排序梯度仍只占 Adapter 上 UAD 梯度的 1.5–2.1%。[C][R]
- H018 同架构仅把 DDP LR 从 0.032 降到 0.008，最终 −2.67/−6.57pp；**配置差异大于多数模块效应**。[R]
- 零初始化 + weight decay 会把小模块压死（SCSR v3）；非零初始化又可能过大（ICRE gamma 增长到 0.436）。[C]
- 固定融合权重（15–20%）把距离分配给弱分支；HiHR 诊断显示 15% 融合 mAP 10.78，α=0.01 回到 11.02。[R]

## 4. 为什么训练初期较好、中期被反超、后期追不上

### 4.1 日志事实：没有“后期绝对下降”

- 所有方法的 mAP/R1 绝对曲线在最后 30 epoch 仍上升；没有“训练损失继续降、验证指标绝对下降”的组合。[R]
- 基线 H014 在 90→120 仍 +0.29 mAP / +0.97 R1；尾段斜率 +0.011/+0.0325 pp/epoch。[R]
- 失败方法大多在 ep10–20 领先，随后饱和；基线继续改善并反超。[R]
- 损失分量 CE/WRT/PCA/GPD 单调下降，无中期尖峰/崩塌；不能用“后期过拟合/原型库崩塌”解释。[R]

### 4.2 机制：早期更快拟合 vs 后期更好的几何

- HiHR Stage2 ep10 CE 已 0.45（Stage1 初始化），但同总预算下 +0.42/−1.14；早期领先部分是预算假象。[R]
- TAUR ep10 +1.44/+4.81，ep90 mAP 首次转负，ep120 −0.45/−0.31；rank 梯度占 Adapter 上 UAD 梯度仅 1.5–2.1%，Adapter 残差 rho=0.1 有界 → 早期适配后饱和。[R][H]
- PAT ep20 +0.63/+1.28，ep70 R1 转负，ep120 +0.02/−0.92；CSL 全程 0，PSD 替换 CE，Part 监督与测试几何不一致。[R][C]
- ViSA ep20 +0.76/+1.33，ep100/120 mAP+/R1−；融合 WRT detach shared、测试固定含 20% local。[R][C]
- SFTC/ICRE 从 ep10 就落后，CE 高于基线，后期损失仍降但指标差距扩大；更像共同训练代价/优化干扰。[R][H]

### 4.3 结论

“早期好、后期差”不是模型后期崩了，而是：
1. 新增容量/预训练/阶段头让方法**更快拟合**；
2. 但新增监督与最终检索几何不一致、或有界子空间不足，导致**提前饱和**；
3. 基线仍在持续优化，最终反超。
**“先到”不等于“到得更高”。**

## 5. 为什么新增模块/机制会伤害检索

### 5.1 排序/对比损失的共同失败模式

- A-V1：MP + Pair/Mixed + 软困难采样，mAP −0.42/R1 −2.06；98.1% 新失败伴随最危险负样本上升。[R]
- B-B：替换 WRT 的 query-risk ranking，mAP −0.15/R1 −2.84。[R]
- WCV1：mixed-gallery rank loss（归一化 CLS、相机过滤、负 logsumexp、正例组均值、梯度预算 rho=0.10），mAP +0.09/R1 −1.33。[R]
- PAT/TAUR/HNSM 等辅助排序/关系损失也出现 mAP↑R1↓ 或 R5/R10↑mAP/R1↓。[R]

**机制假设**：
- 新损失在 batch 内候选上优化，候选分布 ≠ 全 gallery；相机过滤/正例预算改变梯度方向。
- 为了降低对比损失，模型可能同时抬高正负相似度（特征更“平坦”），或把梯度集中在最危险负样本，导致 top-1 margin 收缩。
- 新损失与 CE/WRT/ProCA/GPD 竞争同一个 CLS；GPD 的全局身份分离被扰动。
- 新分支改变预训练注意力路由/特征几何（SFTC 联合 softmax、ICRE 残差写回）。

### 5.2 全局特征后处理的失败

本轮离线实验（同一 H014 特征）[R]：

| 方法 | mAP | R1 | 结论 |
|---|---:|---:|---|
| 基线 | 11.02 | 29.71 | — |
| 逐模态 mean | 11.03 | 29.65 | 无效 |
| 逐模态 z-score | 10.59 | 26.84 | 退化 |
| 逐模态中心化 | 11.06 | 29.48 | 无效 |
| 逐模态 ZCA | 4.07 | 20.98 | 灾难 |
| 模态 CORAL | 9.91 | 26.15 | 灾难 |
| LDA | 10.48 | 26.98 | 退化 |

- UAD 的特征几何已经与训练目标高度匹配；无监督/监督线性变换都会破坏身份方向。
- 分数校准（逐模态 mean/z-score）只改变跨模态竞争，不能解决排名本身；z-score 反而伤 R1。
- QE 可以 +mAP（λ=1 时 +3.2pp），但 R5/R10 大幅下降；λ=0.1 时 mAP +0.86、R5/R10 −2.4；门控后收益几乎消失。

### 5.3 模块与 baseline 不协同的原因

- UAD 的四项损失分布在不同特征空间（BNNeck / raw pre-BN / normalized pre-BN）；新增模块往往只改其中一条路径。
- GPD 是主要增益来源（Table 8：单独 +2.0 mAP/+4.8 R1）；ProCA 单独仅 +0.4/+0.6；CE 在后期接近饱和。
- 新增排序损失会扰动 GPD 已建立的全局原型几何；新增分支消耗共享容量。
- 平台维度未被建模；ProCA 中心混合 ground/aerial；GPD 原型也混合平台。
- 训练/评测候选不一致（同相机负样本）使新增监督方向偏离最终排序。

## 6. 为什么参考论文/开源代码的方法迁移到 UAD 会失效

1. **任务/数据不同**：源方法多针对 VI-ReID、AG-ReID、域泛化 ReID；WHU-MARS 是 any-scenario、三模态、平台混合、长尾 TIR。源方法的配对/同步数据、backbone、batch、评测协议不同。
2. **基线缺口不同**：源方法的增益可能来自填补其 baseline 缺失的机制；UAD 已有 ProCA/GPD，重复机制边际收益小。
3. **实现适配改变机制**：M-SpecGene 位置编码轴错配、PAT CSL 未归一化/同相机邻居、SCSR 零初始化 dead、RLE 伪彩色扰动、PEFT 末层空路径。很多“迁移失败”是**实现/终端路径失败**，不是方向本身无效。[C]
4. **训练预算/优化不同**：CLIP-ReID 用 Adam + 两阶段；UAD 用 SGD + 单阶段；ViT-L 同时改 batch/LR；HiHR 两阶段预算不对等。配置差异可大于模块效应（H018）。[R]
5. **源方法的消融条件不可直接搬**：固定权重 ON>OFF 只说明“共同训练权重上的即时补偿”，不等于整体优于独立 baseline（SFTC +0.92/+1.36 ON−OFF，但 OFF 已比 baseline 低 1.92/4.48）。[R]
6. **目标冲突**：PAT CSL 的跨身份局部相似性、TAUR 的 TIR 排序、A-V1 的混合 gallery 对比，与 UAD 的身份排斥/全局原型存在目标张力；未测梯度夹角，不能声称已证冲突。

## 7. 设计规则（从失败中提炼）

### 7.1 必须做

1. **终端路径检查**：新增输出必须能到达最终检索特征；否则不进入方案。
2. **监督对象 = 推理特征**：主损失/新增损失应作用于同一个 pre-BN CLS（或明确说明只用于训练且如何回传）。
3. **归一化顺序固定**：L2、BNNeck、ProCA 中心、GPD 原型的顺序必须与推理一致；新增组件不得改变已有顺序。
4. **训练-评测候选一致**：相机过滤/同相机负样本权重、正样本定义、gallery 候选规模要尽量对齐。
5. **低容量、可关闭、可消融**：每个组件有配置开关；先验证单变量。
6. **先免训练诊断，再训练**：用已有特征/日志验证假设；不做需要重训的无意义验证。
7. **保留 UAD 四项损失结构**：CE + WRT + 0.01 ProCA + GPD；不新增排序/对比损失。
8. **关注后期动力学**：方法必须在基线仍在改善的后段保持增益，不能早期饱和。

### 7.2 禁止/慎用

- 在共享 CLS 上新增 pairwise/listwise/mixed-gallery 排序损失。
- 固定大权重融合（>5–10%）局部/辅助分支。
- 零初始化 + weight decay 的小模块（容易 dead）。
- 未归一化点积 + 低温度（容易饱和）。
- 训练用随机 ROI/增强、测试不用（train-test mismatch）。
- 将 NIR/TIR 当三通道伪彩色做独立通道扰动。
- 全局白化/CORAL/LDA/分数 z-score 后处理。
- 用测试集挑选中间 epoch 或融合权重。

## 8. 对下一步方案的直接约束

1. 单模型方案的主线应是 **训练动力学 + 现有损失内部改进**，不是新增模块。
2. 主要未尝试杠杆：延长/继续训练、LLRD、EMA、model soup、flip TTA。
3. 可修正的现有机制：WRT 的相机掩码/归一化几何、GPD 的原型初始化/EMA/温度、ProCA 的中心可靠性。
4. TIR/平台是最大结构缺口，但简单特征校准已失败；应优先用训练期轻量改动（输入标准化、模态分类头、两阶段 TIR adapter）验证。
5. 若单模型仍差 0.3–0.5pp，Plan B 是 UAD + CLIP-ReID 的互补集成（CLIP 已达 mAP 12.0，且与 UAD 模态对互补）。
