# 指标现象分析：mAP / R1 / R5 / R10 / mINP 的结构、分化与噪声

> 范围：UAD/ViT 实验（05_Results.csv 中 H0xx 系列 + WDV1-A0），不含 CLIP 实验。
> 证据标记：**[代码事实]** 直接读代码/日志；**[实验支持]** 由 CSV/逐 query 数据统计；**[机制假设]** 需后续免训练诊断验证。
> 本文不做逐方法复盘（见 `final_docs/01_diagnosis_synthesis.md`），只做指标层面的横向统计与解释。
> 单位：除特别说明外，Δ 为 pp（百分点）；mINP 为 %。

## 0. 十条结论（先给答案）

1. **mAP 与 R1 在“模块级效应区间”里几乎正交**：|ΔmAP|≤0.6pp 的 32 个实验上 corr(ΔmAP,ΔR1)=**0.379**，而 corr(ΔmAP,ΔmINP)=**0.808**、corr(ΔR1,ΔmINP)=**−0.084**。全量 45 个实验的 0.992 是被大退化样本（RLE/ICRE/M-SpecGene/L3-L6）撑出来的假相关。
2. **mINP 与 mAP 同族（覆盖/深度），不是 R1 的同族**。45 个实验中无一例 “ΔmINP<0 而 ΔR1≥0”；但 “ΔmINP>0 而 ΔR1<0” 有 12 例。
3. **九组合与总体不是并集关系，而是“加性 vs 取最大”**：ΔmAP(overall)≈0.90×mean₉(ΔmAP)，ΔR1(overall)≈1.51×mean₉(ΔR1)；但**相对变化 Δ/M 在两个协议间一致**（slope 1.02 / 0.98）。绝对差只是操作点不同（11.02 vs 12.29；29.71 vs 19.12）。
4. 总体 R1(29.71) ≈ 同模态 R1(30.40) −0.69pp：**混合 gallery 是“更难 0.7pp”，不是“并集红利”**。九组合均值 19.12 之所以低，是因为 6/9 格是跨模态对，本来就不该被平均进“最佳可选正样本”。
5. **mAP 由头部 query 决定，R1 由全体 query 决定**：Top-10% query 贡献 39.9% 的 AP，Top-20% 贡献 61.9%，后 50% 只贡献 9.2%；而 R1 每 query 等权（1pp=64 query）。
6. **1pp R1 是 64 个 query 的净翻转**；A-V1 的净 −2.06pp 实际是 472 新失败 vs 340 新成功。近失配窗口 |margin|<0.02 占 16.5% query，其中 39.9% 会翻转 top-1。
7. **失败的主因是“最危险负样本被抬高”，不是“正样本变差”**：472 个新失败中 267 个（56.6%）正样本相似度还上升了，只是负样本上升更多；463/472（98.1%）伴随 best-negative 上升。
8. **A-V1 全库几何变好、检索指标变差**：负样本均值 0.0211→−0.0019（↓0.023），但每 query 的 best-negative 0.556→0.595（↑0.039）、best-positive 0.502→0.531（↑0.029）。**检索只看上尾，不看均值。**
9. **损失与指标在健康区间解耦**：DDP 组 corr(CE_final,mAP)=−0.53（被欠拟合点拉动）；健康簇 CE 0.105–0.13 内 mAP 跨 8.29–11.44。TAUR CE 最低（0.071）却 mAP −0.45。后期“被反超”是**斜率差**：基线 R1 尾段 +0.0325 pp/ep，TAUR +0.0025、PAT +0.017。
10. **WDV1-A0 不是失败的方法，而是空对照**：从 UAD-120 权重、LR=6.4e-5（峰的 1/500）、constant、30 epoch。LR 积分仅为基线的 **0.14%**。结果 mAP 11.03 恒定、R1 29.68→29.51（−0.17）。它标定的是**“同模型再训 30 epoch”的噪声带：±0.01 mAP / ±0.2 R1**。

## 1. 指标定义与结构

### 1.1 代码事实

| 指标 | 计算 | 代码位置 | 结构含义 |
|---|---|---|---|
| mAP | 每 query `AP = Σ_k (prec@k · hit_k)/num_rel`，再对 query 宏平均 | `WHU/utils/metrics.py:181-188`；overall 走 `eval_func_top_k:119-126` | 对**全部正样本的排名位置**积分；num_rel = 同 ID 且不同相机的全部 gallery 数 |
| R1 | `cmc[0]`，首个正样本是否在首位 | `metrics.py:174-177` | 只对一个决策位敏感；每 query 等权 |
| R5/R10 | `cmc[4]` / `cmc[9]` | 同上 | 首个正样本的进入速度 |
| mINP | `num_rel / (last_relevant+1)` | `metrics.py:190-192` | **最后一个正样本**的位置；尾部覆盖 |
| 同相机剔除 | `remove = (g_camids[order] == q_camid)`，注意是 **sysu 版**（只按相机，不按 (pid,cam)） | `metrics.py:98-99, 163-164` | 每 query 的候选池 = 全库去掉自己相机；num_rel 也随之变化 |
| 截断 | overall 用 `top_k=50000` 截断索引，但 `num_rel` 仍用全库正样本数 | `metrics.py:474-481, 90-91` | [代码事实] 对正样本排在 5 万以后的 query，AP 被机械压低 |

**两条容易被忽略的代码事实**（会直接影响“总体 vs 九组合”的比较）：

- **[代码事实] overall 与九组合不是同一个函数**：overall 走 `eval_func_top_k`（gallery 93609 → 截断 50000），九组合走 `eval_func`（gallery 31203，不截断）。所以两边的 mAP 不只是“候选池大小”不同，还多了一层截断偏差。
- **[代码事实] 正样本数 num_rel 是“同 ID 且不同相机”的**，一个 query 的中位正样本数是 **105**（min 18，max 666，mean 124.7；A-V1 retrieval_queries.csv）。因此 mAP 天然是“105 个正样本的排序质量”，R1 是“1 个决策”。

### 1.2 各指标对什么敏感（用本数据集的数据量化）

**（a）正样本覆盖 → R1/mAP 同向**

| 正样本数 | query 数 | UAD R1 | UAD mAP |
|---|---:|---:|---:|
| 20–49 | 1302 | 22.96% | 8.92% |
| 50–99 | 1749 | 26.47% | 10.25% |
| ≥100 | 3342 | 34.05% | 12.27% |

*[实验支持] A-V1 `retrieval_queries.csv`，按 `uad_positive_count` 分桶。* 正样本越多，top-1 被“任意一个正样本”命中的机会越大，mAP 的积分也越长。**这就是“覆盖”对两个指标的共同作用面**。

**（b）top-1 边界 → 只有 R1 敏感**

- UAD 每 query 的 `margin = best_positive − best_negative`：mean **−0.0539**，median **−0.0475**，p90 +0.0582。**中位 query 的最危险负样本比最佳正样本高 0.0475**。
- 只有 1903/6405 = **29.7%** 的 query margin>0，与 R1=29.71% 完全一致（这正是 R1 的定义）。
- 首个正样本排名：median **7**，p90 **243**，p99 **2708**。所以“首个正样本进前 10”只有 54.55%，进前 5 46.32%。

**（c）尾部 → 只有 mINP 敏感**

- 最后一个正样本的位置：median **30,518** / 81,009（≈37% 深度），p90 63,682。overall mINP = **0.6595%**（WCV1 report 原文，`WCV1/logs/diagnosis_120/report.md`），即“正样本数/最后正样本名次”。
- 含义：**mINP 衡量的是“最差的那个正样本落在多深”**。在本数据集上它几乎是纯尾部指标，与 top-1 无关。

**（d）AP 的分布极不均匀**

| 分组 | 占 mean AP |
|---|---:|
| Top 10% query | 39.9% |
| Top 20% query | 61.9% |
| Bottom 50% query | 9.2% |

*[实验支持] 按 `uad_AP` 降序累加。* 这直接解释了 **mAP 与 R1 不可互代**：mAP 的方差由 640 个最好的 query 主导，R1 的方差由 6405 个 query 的边界共同决定。任何“只改善好 query 的第 2–100 名”的改动都会抬 mAP 而几乎不动 R1；任何“只挪动边界附近 query”的改动会动 R1 而几乎不动 mAP。

### 1.3 总体 vs 九组合：加性 / 取最大 的双结构

用 45 个实验（每个实验对齐自己的 baseline）做回归：

| 关系 | 绝对 Δ 斜率 | 相对 Δ 斜率（按各自操作点归一） | 平均绝对偏差 |
|---|---:|---:|---:|
| overall ΔmAP ~ mean₉(ΔmAP) | **0.908** | **1.019** | 0.086pp |
| overall ΔR1 ~ mean₉(ΔR1) | **1.51** | **0.978** | 1.20pp |

*[实验支持] `05_Results.csv` 全量 H0xx；操作点：mAP 11.02 vs 12.29（比 0.897），R1 29.71 vs 19.12（比 1.554）。*

**解读（这是本节的核心）**：

- **mAP 是加性的**：AP 对 query 的 105 个正样本（分属 3 个模态）求和，所以总体 mAP 的变化 ≈ 九个组合变化的平均。相对变化在前者≈后者（1.02）。
- **R1 是取最大的**：top-1 只有一个决策位，query 只要在**任一**模态里有一个正样本赢下首位就算命中。所以总体 R1 的水平接近“同模态 R1”，而不是九格平均。
- 实测：**overall R1 29.71 vs 同模态 pair R1 均值 30.40（−0.69pp）**；按 query 模态拆分（A-V1 `modality_pair_summary.csv` 的 Mixed 行）：

| query 模态 | Mixed R1 | 同模态 pair R1 | 差 |
|---|---:|---:|---:|
| RGB | 40.05% | 42.48% (RGB→RGB) | −2.43 |
| NIR | 29.18% | 27.96% (NIR→NIR) | **+1.22** |
| TIR | 19.91% | 20.75% (TIR→TIR) | −0.84 |
| 加权 | 29.71% | 30.40% | −0.69 |

  → **混合 gallery 的净效应是“竞争惩罚 ≈0.7pp”，不是“多模态并集红利”**。多出来的跨模态候选既是正样本也是负样本，负样本更多（93609 vs 31203）。

- **所以“九组合与总体不一致”是绝对尺度的错觉**：把两边的 Δ 分别除以各自的操作点，二者一致到 2–3%。真正会“不一致”的只有符号，而符号翻转只出现在 |Δ|<0.5pp 的噪声区（如 H021：overall ΔR1 −0.50，mean₉ +0.26）。

### 1.4 为什么 mAP 与 R1 不可互代（三个可量化的理由）

1. **权重不同**：R1 每 query 等权；mAP 按 AP 加权（top-20% 占 62%）。
2. **敏感的对象不同**：R1 = 1{margin>0}（阈值穿越）；mAP = 全部正样本的名次积分（含 30k 名以后的尾部）。
3. **效应量不同**：在 |ΔmAP|≤0.6 的 32 个“现实模块”实验里 corr(ΔmAP,ΔR1)=**0.379**；同一批里 corr(ΔR5,ΔR10)=0.902、corr(ΔmAP,ΔmINP)=0.808。**R1 是这套指标里方差最“独立”的一个。**
4. **反例密度**：45 个实验里，mAP 与 R1 符号不一致 8 例；mINP 与 R1 符号不一致 12 例。

### 1.5 噪声底（后续所有“效应”都要拿它作尺子）

| 噪声来源 | 量级 | 证据 |
|---|---|---|
| 评测确定性 | **0**（同权重两次评测完全相同：H013/H016/H017 与 H014 全部 Δ=0.00） | [实验支持] 05_Results |
| 权重微漂移（A0：30 epoch × 6.4e-5） | **mAP ±0.01pp，R1 ≤0.2pp**（29.68→29.73→29.70→29.65→29.56→29.51，非单调到单调下降） | [实验支持] A0 日志 |
| seed（同方法不同种子，DDP） | **mAP 0.24pp，R1 1.13pp**（H005 11.30/29.37 vs H006 11.06/28.24） | [实验支持] 05_Results |
| 协议/子集（同权重，1000 vs 1000GD 子集） | **mAP +3.38，R1 +1.90，R5 −0.18，R10 −0.99**（H015，同一 checkpoint） | [实验支持] 05_Results R0159 vs H015 |

**结论**：任何 |ΔmAP|<0.3 或 |ΔR1|<1.1 的方法差异都在 seed 噪声内；任何 |ΔR1|<0.2 的差异连 A0 的漂移带都不出。**H015 尤其重要：不改任何权重，只换评测子集，就能造出“mAP/R1 升、R5/R10 降”的教科书式分化，幅度比绝大多数模块大一个量级。**

### 2.2 三个横向统计

1. **“mAP↑R1↓”是真实的、可复现的方向，但幅度小**：A 类 6 个严格例子的 ΔmAP 都在 +0.02…+0.42，ΔR1 在 −0.34…−1.14；除 H006 外都伴随 **mean₉ΔmINP>0**。
2. **“R5/R10↑”必然伴随 mINP↓**：B 类四个实验的 mean₉ΔmINP 全部 ≤0.001（TAUR −0.266、WQVD-A2 −0.018、SCSR −0.001、PEFT −0.012）→ **提升 5–10 名的代价是尾部正样本变差**（把正样本从深处拉到 5–10 名，但拉不到第 1 名）。
3. **全量相关是假的**：45 个实验 corr(ΔmAP,ΔR1)=0.992；剔除 |ΔmAP|>0.6 的 13 个大退化样本后只剩 **0.379**。任何用“mAP 和 R1 高度相关”来论证“指标冗余”的说法，都是被 RLE/M-SpecGene 这类坍塌样本误导。

### 3.2 哪些方法“TIR 小升但 RGB 掉”

- **TAUR v2**：ΔR1 TIR +0.14、NIR +0.30、**RGB −0.69**；ΔmAP RGB −0.79 是 TIR −0.25 的 3 倍。
- **ViSA s1234**：ΔR1 TIR +0.17、NIR −0.05、**RGB −0.47**。
- **ViT-L**：ΔR1 NIR +0.92、TIR +0.06、**RGB −0.20**，但 ΔmAP RGB +0.48 最高 → 它损的是 RGB 的 **top-1 边界**，不是 RGB 的覆盖。
- 机制共性 [机制假设]：这三者都在**共享 CLS 上叠加/重标定**，而 RGB 是样本最多、类内最紧凑的模态；共享主干的改动先牺牲“最容易的模态”的 top-1 边际，换来弱模态的覆盖。A-V1 给了同构证据：A1 的 RGB_Aerial R5 −6.2pp（`group_comparison.csv`），受损最重的正是最强的子群。

### 3.3 哪些方法“只伤强模态”

- **RLE E1–E4**：ΔmAP RGBq −2.9…−3.2，而 NIRq −0.7…−1.0、TIRq −0.3…−0.5。**E2 关掉 TIR 扰动后损失不变**（−2.94 vs −3.03）→ 伤害不是“TIR 增强”造成的，而是**对 RGB 输入的通用扰动**。这是排除“TIR 专项失效”假说的关键对照 [实验支持]。
- **ICRE**：ΔmAP RGBq −3.63 是所有 query 模态里最差的一格。
- 一般规律：**伤害按模态的“容易程度”排序**，RGB 最先受损。这与“RGB 的正样本最密（同 ID 样本多在 RGB 内）、其 top-1 边界最拥挤”一致。

| 量 | UAD | A1 | Δ |
|---|---:|---:|---:|
| 同模态正样本均值 | 0.3493 | 0.3566 | +0.0073 |

## 5. 损失—指标关系

### 5.1 损失是“训练集的可分性”，指标是“开集 6405 query 的边界”

- 训练用 PKM（`NUM_INSTANCE: 4`），每个 batch 内 ID 数约 64；CE 下降意味着**训练 ID 在 batch 内可分**，与 93,609 张 gallery 的开集 top-1 无直接对应关系 [代码事实 + 机制假设]。
- 实测（epoch_metrics.csv 末 epoch）：

| 组 | n | corr(CE,mAP) | corr(CE,R1) | 备注 |
|---|---:|---:|---:|---|
| DDP | 15 | **−0.526** | −0.554 | 被 H018（CE 0.982）和 H025 拉动 |
| single | 17 | −0.929 | −0.942 | 被 M-SpecGene（1.37）和 RLE（0.56–0.69）拉动 |

- **反例（同配方 DDP，健康簇 CE 0.105–0.13）**：H031 TAUR CE **0.071（全场最低）** → mAP 10.57（低于基线）；H014 CE 0.106 → 11.02；H025 CE 0.1135 → 8.29。**CE 与 mAP 在 0.10–0.13 区间内没有单调关系。**
- 损失的尺度本身被配方污染：DDP CE≈0.105–0.13，single CE≈0.37（batch 256 vs 64、损失归一化不同），**跨模式比损失无意义**。

### 5.2 “损失单调下降、指标不动/下降”的三个已证实路径

1. **饱和**：90→120 的损失斜率是 −0.0002…−0.0016/ep（`log_trajectory_report.md` §6.2），几乎为零；同时指标斜率 +0.01…+0.02 pp/ep。**损失早已进入平台，指标仍在缓慢爬**。
2. **几何重新分配**：A-V1（不同方法族）证明“全局负样本均值下降、上尾上升”可以同时发生；A0 证明在损失完全平的情况下 R1 仍能漂 −0.17pp。
3. **训练-测试几何错配**：PAT 的 Part Token 只在训练时参与、测试只用 CLS；ViSA 的融合距离含 20% local 但融合 WRT 对 global detach（`log_trajectory_report.md` §8.1）。

### 5.3 早期领先 → 后期被反超：是斜率，不是绝对下降

| 实验 | ep10 ΔmAP/ΔR1 | ep120 ΔmAP/ΔR1 | 尾 30 轮 R1 绝对斜率 | 基线 R1 斜率 |
|---|---:|---:|---:|---:|
| H031 TAUR | +1.44 / +4.81 | −0.45 / −0.31 | +0.0025 | **+0.0325** |
| H032 PAT | +0.10 / +0.45 | +0.02 / −0.92 | +0.0170 | +0.0325 |
| H005 ViSA | +0.49 / +1.20 | +0.28 / −0.34 | +0.0390（但轨迹震荡） | +0.0325 |
| H001 HiHR | +4.05 / +9.38（含 60ep Stage1 预算） | +1.54 / +1.58（同轮）/ +0.42 / −1.14（同预算） | +0.0200 | +0.0325 |

→ **所有“后期落后”都是因为基线在 90→120 仍在以 +0.0325 pp/ep 上升（mAP +0.29/R1 +0.97），而方法提前饱和。** 没有任何实验出现绝对指标下降（`log_trajectory_report.md` §8.3）。

### 6.4 结论：是四者中的哪一个

- **不是收敛失败**：损失已经与基线终点一致（CE 0.106→0.107），训练 acc 97.7%。
- **不是过拟合**：训练损失不升；且“过拟合”要求验证绝对下降，这里 mAP 完全不动。
- **不是“LR 不足”意义上的调参问题**：A0 的定义就是“用终末 LR 继续”，它是一次**空对照**（配置文件首行注释写明：“continue the 120-epoch UAD solution at its terminal LR”）。
- **是指标噪声 + 训练配方已到极限**：在 LR 积分只有 0.14% 的情况下，模型只能沿损失面的平坦方向做随机游走，结果是 mAP 冻结、R1 缓慢下漂。**A0 的真正价值是给出了“同模型再训”的噪声带：±0.01 mAP / ±0.2 R1。**
- 若要验证“训练配方已到极限”的反面，需要 A1（LR 5e-4、60 epoch 余弦）或 A2（200 epoch 从头），但按 seed 噪声（1.13pp R1）推算，A1 若只带来 <1pp 的 R1 变化，仍无法与种子方差区分 [机制假设]。

## 7. 机制需求反推（按指标）

以下每条都是“从指标现象反推的、可用免训练诊断验证的假设”。

### 7.1 要同时抬 mAP 和 R1，需要改变哪种排序结构？

**现象**：A 类方法（HiHR/ViSA/ViT-L/PAT）都抬了 mAP/mINP，却掉了 R1。A-V1 的分解显示：rank≥2 的桶全部改善、rank-1 桶崩塌。

**反推**：需要的是**把 margin 分布整体右移**，而不是把正样本从深处拉到浅处。

- 当前 margin 分布：median −0.0475，p90 +0.058。要让 R1 从 29.7% 升到 35%，需要约 340 个 query 的 margin 从 −0.05 附近穿过 0。
- A1 的做法（把 best-positive +0.029、best-negative +0.039）方向就是错的：**它把分布整体展宽，而不是平移。**

**可验证**：用已保存的 UAD/A1 特征，做 `s' = s − α·(hard-negative cluster center)` 或温度重标定，扫描 α，画 (ΔmAP, ΔR1) 曲线。**预测：存在一个 α 区间使 mAP 小升而 R1 不降**；而且 R1 的变化率 ≈ 边界壳内 query 密度的变化率（~0.05 宽度内 2497 个 query）。

### 7.2 如果只抬 R5/R10，通常牺牲什么？

**现象**：B 类（TAUR、WQVD-A2、SCSR-V4.1、PEFT）R5/R10 升、mINP 全部 ≤0。

**反推**：牺牲的是**尾部覆盖**与**首位集中度**。把第 1 名的正样本“摊平”到第 2–10 名：P(rank≤10) 升、P(rank=1) 降、最后正样本更靠后。

**可验证**：在特征上做“top-k 邻域平均”（把每张图的特征与其 k 近邻原型平均），k 从 1 扫到 10。**预测：k↑ 时 R5/R10↑、R1↓、mINP↓**，与 TAUR 的签名一致。这是纯后处理，不需要重训。

### 7.3 为什么“全局原型”GPD 能同时抬 mAP/R1，而 batch-local 排序损失不能？

- **[实验支持]** UAD 的 GPD 从 1.64 单调降到 0.08，与 mAP 从 5.78 升到 11.02 同向；而 TAUR 的 rank loss 对 Adapter 的梯度只有 UAD 的 0.04%→1.8%，且只在 Adapter 残差（rho=0.1）内生效，最终 mAP −0.45。
- **[机制假设]** GPD 的原型是**全局、跨 batch、跨模态、EMA 慢更新**的同一 ID 锚点；它把该 ID 的**所有**正样本（中位 105 个）同时拉向一个共同中心 → 直接改变正样本分布的整体位置（抬 mAP/mINP 的那一半）。而 batch-local 排序损失只重排 **P×K=256** 个样本的相对次序，且梯度被主损失淹没 → 只能改变局部次序，不能移动全局分布。
- **可验证（免训练）**：从已保存特征计算每个 ID 的 prototype，度量 `sim(x, own prototype) − sim(x, nearest other prototype)`。**预测：UAD 的这个量对全部正样本都是正的且分布集中；A1/TAUR 类方法的这个量在 top-1 上更差但在 2–10 名上更好**。若成立，则“原型可靠性”而不是“排序损失强度”是 mAP/R1 的共同杠杆。

### 7.4 哪些指标对“场景原型/平台结构”最敏感？

- **[实验支持]** 协议难度：`same_modality_same_platform` mAP 20.08 → `modality_only` 9.80（−10.3pp）；`platform_only` 21.89（≈无损）。**mAP 对“模态”极敏感，对“平台”几乎不敏感。**
- **[实验支持]** 最危险负样本：71.4% 同平台、67.7% 同模态、0% 同相机。
- **反推**：mAP/mINP 的方差主要由**模态内的场景/相机近邻**决定（因为要击败 105 个正样本的尾部）；R1 的方差由**模态内的近邻上尾**决定。平台维度只影响“是否被允许成为候选”，不影响排序难度。
- **可验证（免训练）**：把每张图的特征减去其“场景中心”（同相机或同 scene 的均值），重算检索。**预测：mAP 大幅上升、R1 变化较小**（因为 mAP 的尾部正样本很多本身是场景近邻，去场景分量会让它们同时上浮）；若反过来 R1 上升更多，则说明 top-1 的竞争主要来自场景近邻而非 ID 判别。

### 7.5 “正样本覆盖”假设

- **[实验支持]** R1 随正样本数单调上升（20–49: 22.96% → ≥100: 34.05%）；H015 同权重换到 1000GD 子集，mAP +3.38/R1 +1.90 而 R5/R10 下降 —— **覆盖结构变了，指标方向就变了，权重没变。**
- **可验证**：对同一份特征，按“每 query 正样本数”重采样 gallery，画 (mAP, R1, R5) 随覆盖的变化曲线；如果 R5/R10 出现与 H015 同向的下降，则说明 R5/R10 不是“更难”的 R1，而是对候选池结构另有依赖。

### 7.6 用于判别“方法真实效应 vs 噪声”的最小实验设计

- 单 seed 的 ±0.3pp R1 效应不可信（seed 噪声 1.13pp）；**至少 3 seed**。
- 报告 Δ 时必须同时报告 `mean₉ΔmINP`：它是 {mAP,mINP} 因子的高信噪比代理（r=0.81），且比 mAP 更不易被截断/协议影响。
- 若 ΔmINP<0，则 ΔR1 必 <0（45/45 无例外）→ **mINP 可作为 R1 的“一票否决”预筛指标**，成本远低于逐 query 诊断。

### 复现口径（避免误读）

- 所有 Δ 都用**运行内对齐的 baseline**（DDP 对 H014，single 对 H019），不能用 11.02 对所有行。
- H015（1000→1000GD）是**同一 checkpoint 换评测子集**，不是模型；它的 +3.38/+1.90/−0.18/−0.99 是“协议效应”，不能当方法。
