## 0. 执行摘要

### 0.1 结论

历史 17 组方法、最新 A-V1/B-B/WCV1、以及本轮 8 类免训练后处理实验共同证明：

1. **继续在 UAD 的共享 CLS 上叠加排序/对比/混合 gallery 损失，会系统性抬高最危险负样本，伤害 Rank-1。**
2. **任何全局特征后处理（逐模态/逐相机/逐平台中心化、ZCA、CORAL、LDA、分数 z-score）都会破坏 UAD 已学好的开放集度量。**
3. **UAD 的瓶颈是训练动力学与开放集度量几何，不是分类边界**：闭集分类已饱和（共享分类器训练 acc 94.9–95.4%，最近类中心 99.9%），但最危险负样本相似度约 0.47–0.54，远高于最难正样本 0.09–0.24。
4. **基线在 120 epoch 时仍在上升**（尾段 mAP +0.011、R1 +0.0325 pp/epoch），且历史所有实验都没有认真尝试延长训练、EMA、model soup、LLRD。延长/稳定优化是最高确定性的未尝试杠杆。
5. **mAP 是绑定约束**：尾段 mAP 斜率只有 R1 的约 1/3。60 epoch 的延长训练大概率给 mAP +0.4–0.6、R1 +1.2–1.9，mAP/R5 仍可能差 0.4–0.6pp。
6. **CLIP-ReID + ProCA + GPD 已经把 mAP 做到 12.0–12.13**（超过 1000 目标 12.0），但 R1 29.2–29.4、R5 46.2、R10 54.1–54.2 未达 +1。CLIP 与 UAD 在不同模态对上互补，**UAD+CLIP 融合是当前证据下 1000 AS 达标概率最高的路径**，但属于双模型。

## 1. 诊断依据（方案为何长这样）

### 1.1 指标结构

- mAP 是逐 query AP 宏平均，AP 取决于所有正样本的位置；R1 只看第一名。
- 顶部边界极脆弱：raw 欧氏与 L2 余弦的 R1 相同，但 top-1 仅 65.8% 一致；大量候选分数接近。
- A-V1：472 个 R1 新失败 / 340 个新成功，净 −132；75% 的新失败仍在前五；mAP 只 −0.42。
- 463/472（98.1%）的 R1 新失败伴随最危险负样本相似度上升；正侧平均只 +0.006，负侧 +0.059。
- mINP 与 R1 可分化（WCV1 mINP 0.724 vs UAD 0.660，R1 −1.33）。
- 九组合各自重建候选 gallery；总体不是九组合平均；TIR 相关五对占 1000 总体 mAP 权重 55.6%；总体 R1 对九组合是次线性并集。
- 平台差异远大于模态：RGB-G↔RGB-A 质心余弦 0.388，而 RGB-G↔NIR-G 0.954、RGB-G↔TIR-G 0.927。

### 1.2 历史失败的三类原因

1. **终端路径/实现失败**：PEFT 末层 DPA 只写 Patch、最终只取 CLS；PAT Part 与 CLS 断开；SCSR v3 残差 3e-8、gate 2.2e-5 数值 dead；M-SpecGene 位置编码轴错配（cos 0.818）；RLE 把 NIR/TIR 当三通道伪彩色扰动。
2. **监督对象/几何不一致**：ViSA 融合 WRT detach shared、测试固定含 20% local；WQVD A1 主损失只监督 z=c+0.05u；TAUR rank 梯度只回 Adapter，占比 1.5–2.1%；PAT CSL 邻居 92.7% 同相机、logit≈992 饱和。
3. **训练动力学/候选覆盖**：A-V1 Pair/Mixed 只在单卡 16-PID batch 内取负例（约 3% 身份覆盖），无梯度预算，标量占比从 11% 升到 34.5%；B-B 同样只覆盖约 3% 负身份，BB 标量占总损失 39–41%；WCV1 4 卡 gather 后仅约 12.6% 身份，正例吸引主导梯度（正/负梯度范数比 1.88），73.5% 的 R1 新失败是纯负例变强。**batch 内排序损失改善的是 batch top-1，不是全库 R1。**

### 1.3 日志动力学

- 所有实验末期绝对指标仍在上升，没有“后期绝对下降”。
- 基线 90→120：mAP +0.29、R1 +0.97；尾段斜率 +0.011/+0.0325 pp/epoch。
- 失败方法多在 ep10–20 领先，随后饱和；基线继续改善并反超。
- 损失分量 CE/WRT/PCA/GPD 单调下降，没有后期爆炸/原型崩塌证据。
- 因此“早期好、后期差”不是模型崩了，而是**新增容量早期更快拟合、随后饱和；基线仍在改善**。

## 2. 设计原则

1. **不新增排序/对比/混合 gallery 损失**；保留 CE + WRT + 0.01 ProCA + GPD 的结构与权重。
2. **不改变推理特征维度**；仍是 768 维 pre-BN CLS，L2 归一化。
3. **所有训练期改动必须沿现有四条损失的数据流/梯度流生效**；不引入“训练用、推理不用”的分支。
4. **低容量、可关闭、可消融**；每个组件有独立配置开关与 gate。
5. **优先训练动力学与几何对齐**，而不是结构堆叠。
6. **一个 stage 只改一个变量**；至少 2 seed + paired bootstrap；预注册 final/EMA/soup。
7. **GD R5/R10 作为护栏**；不在 GD/AG 测试集上调参。
8. **Plan B 明确披露**：双模型融合不冒充单模型。

## 3. 方案总体结构

```
Track 1 单模型 UAD
  H014 (120 epoch)
    ├─ A0: 恒低 LR 30 epoch（首选）
    ├─ A2: 200 epoch 从头（干净长 schedule）
    ├─ 可选 LLRD（仅 A2，decay 0.85–0.9）
    ├─ GPD 三模态暖启动（finetune 必需）
    ├─ 可选 CA-WRT（仅压同相机负样本）
    ├─ 可选 EMA / model soup
    └─ flip TTA
Track 2 UAD+CLIP 融合
  UAD 特征 + CLIP-ReID 特征
    ├─ 分数融合 α=0.5
    ├─ RRF
    └─ 特征拼接（诊断）
```

主损失不变：

$$
\mathcal{L}=\mathcal{L}_{CE}+\mathcal{L}_{WRT}+0.01\mathcal{L}_{ProCA}+\mathcal{L}_{GPD}
$$

本方案新增的是**训练轨迹、损失掩码、原型初始化、推理增强**，不是新的损失项。

## 4. 组件详细设计

### 4.1 组件 A：A0 恒低 LR 延长训练（首选）

**目的**：直接检验“基线尾段仍在上升”。不重启高 LR，只在基线终段 LR 上继续 30 epoch。

**配置**（DDP；单卡用括号内值）：
- 初始化：`PRETRAIN_CHOICE='finetune'`，`PRETRAIN_PATH=H014/transformer_120.pth`；完整加载 backbone + BNNeck + classifier。
- `MAX_EPOCHS=30`
- `BASE_LR=6.4e-5`（单卡 `1.6e-5`）
- `SOLVER.SCHEDULER='constant'`：所有参数组（含 bias）固定为 `BASE_LR`，真正复现基线终段 LR
- `LR_MIN_FACTOR=1.0`：仅作为 cosine 回退；constant 模式不使用
- `WARMUP_EPOCHS=0`
- `CHECKPOINT_PERIOD=10`，`EVAL_PERIOD=5`
- 其余：SGD momentum 0.9、WD 1e-4、bias ×2、PKM batch 256（单卡 64）、seed 1234、损失权重不变。

**为什么是 6.4e-5**：原调度 `lr_min=0.002*BASE_LR`，DDP `BASE_LR=0.032` 的终段 LR = 6.4e-5；单卡 `0.008` 的终段 = 1.6e-5。A0 是“继续同一轨迹”，不是第二段 cosine。

**正向数据流**：与原 UAD 完全一致；三模态 tuple → `[RGB;NIR;TIR]` → ViT → pre-BN CLS → CE/WRT/ProCA/GPD。

**反向梯度流**：四项损失仍汇合到共享 ViT；无新增分支；无 detach 变化。

**参数**：无新增可训练参数；仅延长优化。

**Gate**：
- 1000 AS：mAP ≥ +0.25、R1 ≥ +0.4、R5/R10 ≥ +0.2，且没有任何指标下降。
- 1000GD R5/R10 不低于 46.0/53.5。
- 若 30 epoch 内 mAP 不升，停止；不要用 R1 升掩盖 mAP 失败。

### 4.2 组件 B：A2 200 epoch 从头训练

**目的**：干净检验“更长 schedule 本身是否有效”，避免 A0 的“继续训练”与“重启”混淆。

**配置**：
- `PRETRAIN_CHOICE='imagenet'`，ImageNet ViT-B/16。
- `MAX_EPOCHS=200`
- `BASE_LR=0.032`（DDP）/`0.008`（单卡）
- `LR_MIN_FACTOR=0.002`
- `WARMUP_EPOCHS=5`
- 其余不变。
- 可选单变量：`MODEL.LLRD_DECAY=0.85` 或 `0.9`；不要与 A0 的低 LR 同时解释。

**Gate**：相对 H014，mAP ≥ +0.5、R1 ≥ +0.8；若 mAP < +0.5，Plan B 升为主线。

### 4.2.1 A1 备选（仅 A0/A2 都失败时）

- 从 120 checkpoint 开第二段 cosine：`MAX_EPOCHS=60`、`BASE_LR=5e-4`（DDP；单卡 1.25e-4）、`WARMUP_EPOCHS=3`、`LR_MIN_FACTOR=0.002`。
- `GPD_WARMSTART=True`、`EMA=True`、`TTA_FLIP=True`。
- 配置：`configs/LRA_UAD_A1.yml`。
- 红队警告：不要用 0.004（终段 LR 的 62 倍）；5e-4 已经是上限。A1 的结果只能作为“第二段 restart”证据，不能替代 A0/A2 的干净结论。

### 4.3 组件 C：LLRD（仅 A2 可选）

**目的**：保护 ImageNet 预训练低层，避免统一 LR 在长训练中破坏表示。

**参数组**（`decay=0.85–0.9`）：
- `base.blocks.i`：`lr = base_lr * decay^(11-i)`。
- `base.patch_embed`：`base_lr * decay^12`。
- `base.cls_token`、`base.pos_embed`：`base_lr * 0.1`。
- `base.norm`：`base_lr * 0.5`。
- `classifier`、`bottleneck`：`base_lr`；bias 再 ×2。
- 其余：`base_lr`。
- WD 不变。

**风险**：全局 cosine floor 可能把低 LR 组反向抬升；`decay=0.5` 会触发，0.85–0.9 不会。A0 不使用 LLRD。

**Gate**：A2 + LLRD 相对 A2，四项至少 +0.1 且无指标下降；否则关闭。

### 4.4 组件 D：EMA 与 Model Soup

**EMA**：
- `ema_p = decay * ema_p + (1-decay) * p`，`decay=0.999`（约 9 epoch 窗口）。
- 每 optimizer step 更新；BN running stats 按浮点 buffer EMA；整数 buffer 复制。
- 所有 rank 保持同一 EMA；保存 `transformer_ema.pth`。
- 训练期验证仍用 final 模型；EMA 只在末轮/测试评估。

**Model Soup**：
- `CHECKPOINT_PERIOD=10`；取最后 3 个 checkpoint（如 180/190/200）。
- 等权平均所有浮点张量（含 BN buffers）；整数张量取第一个。
- `tools/model_soup.py`。

**预注册**：主结果默认 final；EMA/soup 作为 post-hoc，必须在同一 stage 上比较；不能看完测试集再选。

**Gate**：EMA 或 soup 相对 final 四项 ≥ +0.1，且无指标下降；否则保留 final。

### 4.5 组件 E：GPD 三模态暖启动（finetune 必需）

**问题**：`PrototypeBank` 不是 `model.state_dict()` 的一部分；H014 只保存模型权重。finetune 若从零 bank 开始，GPD 的未初始化类 logits 为 0，前几步梯度会把已训练特征拉走。

**做法**：
1. 用 `model.eval()` + `torch.no_grad()` 遍历训练集的 RGB/NIR/TIR 三个确定性 loader（`train_normal_loaders`，无随机增强）。
2. 每张图取 pre-BN CLS，L2；按 PID 累加，求均值，再 L2。
3. 写入 `PrototypeBank.prototypes`；`counts=1`（表示已更新一次，避免 count-aware EMA 首次覆盖）。
4. DDP：rank 0 计算，`dist.broadcast` prototypes/counts 到所有 rank；其他 rank 等待。
5. 记录覆盖率、样本数、step-0 GPD loss；若 GPD loss 仍从 >5 开始，暖启动未生效。

**梯度**：暖启动是 no_grad buffer 初始化，不进入计算图；GPD 对当前特征的梯度仍经 L2 特征回传；原型不接收梯度。

**Gate**：step-0 GPD loss 明显低于 5；1000 AS 四项不下降。暖启动本身不是 +1 杠杆，主要价值是避免 finetune 冷启动破坏。

### 4.6 组件 F：CA-WRT（仅压同相机负样本）

**问题**：评测排除所有同相机 gallery；WRT 只按 PID 分正负，同相机异身份仍是普通负样本。

**做法**：
- processor 构造 `camids_cat = torch.cat(camids, dim=0)`，与 `[RGB;NIR;TIR]` 特征顺序一致。
- WRT 计算 `same_cam = camids_i == camids_j`。
- **正样本不变**：`pos_mask = is_pos`。同相机正样本包含跨模态正样本，是 TIR/NIR 对齐的主要信号，不能降权。
- 负样本：`neg_mask = is_neg * (1 - same_cam) + is_neg * same_cam * w_neg`，`w_neg=0.25`（可配 0/0.25/0.5/1）。
- 若某行负样本全被压到 0，回退到原 `is_neg`。
- 对角线保持原 WRT 行为（自匹配距离≈0，权重极低）。
- `softmax_weights` 仍按掩码归一化；SoftMarginLoss 不变。

**前提**：先运行 `tools/camera_pair_stats.py`。若同相机负样本占比 <5%，或同相机负样本不是最危险负样本，CA-WRT 不值得做。

**Gate**：相对同 stage 的 UAD control，R1 ≥ +0.2 且 mAP 不降；否则关闭。不要与 LLRD、NWRT、camera sampler 同时开。

### 4.7 组件 G：Flip TTA

**做法**：
- `f1 = model(img)`；`f2 = model(torch.flip(img, dims=[3]))`。
- `f = normalize(f1) + normalize(f2)`；评测器再 L2。
- 2× 前向；训练不变。

**Gate**：1000 AS 四项全部 ≥ +0.15 且无指标下降才保留；若 TIR/航拍掉点，关闭。

### 4.8 可选单变量：PMC / MSIN（未纳入本轮代码）

**PMC（每模态分类器）**：
- 3 个 `Linear(768,C)`，共享 BNNeck；CE 按模态路由；推理仍用 pre-BN CLS。
- 动机：TIR 分类边界不被 RGB/NIR 主导。
- 风险：闭集 CE 已饱和（共享 94.9–95.4%，每模态 97.5–98.4%），收益可能很小；MDReID 的 +13.4 mAP 来自不同数据/基线。
- 只做单变量 120 epoch 消融，不作为核心。

**MSIN（TIR 逐图标准化）**：
- TIR 在 ToTensor 后、Normalize 前做 `(x-mean)/std`。
- 动机：热红外对比度/强度分布差异。
- 风险：去掉热对比度身份线索；RLE 的输入扰动失败是警示。
- 只在 TIR 仍是瓶颈时做单变量消融。

### 4.9 Track 2：UAD + CLIP 特征/分数融合

**证据**：CLIP mAP 12.0–12.13，UAD R1 29.71；CLIP 在 NIR→NIR/TIR→RGB 更好，UAD 在 TIR→TIR/RGB→RGB R1 更好。

**流程**：
1. 用 `tools/dump_features.py` 在同一 manifest 上导出 UAD 的 q/g 特征。
2. 用 WC/CLIP 的 `test_whu_mars.py` 改一个保存分支，导出 CLIP 的 q/g 特征（键：`<modality>/<basename>`）。
3. 用 `tools/fuse_features.py`：
   - `score`：`S = (1-α) S_UAD + α S_CLIP`，默认 α=0.5。
   - `rrf`：`1/(k+rank_UAD) + 1/(k+rank_CLIP)`，k=60。
   - `concat`：`[sqrt(1-α) f_UAD, sqrt(α) f_CLIP]`，L2（诊断用，含交叉项）。
4. 评测：总体、九组合、AG；同时报告 UAD 单模型、CLIP 单模型、融合三者。
5. α 只在训练/验证或预注册的固定值上选；不在测试集扫。

**预期**：若两模型 top-1 错误集重叠 60–75%，融合可把 R1 从 29.2–29.7 抬到 30.5–31.5，mAP 从 12.0–12.1 抬到 12.4–13.0。若错误重叠高，可能只到 30.0–30.3。

**公平性**：双模型、双倍参数/推理；必须明确标注“双模型互补集成”，不能冒充单模型。2337 需要 CLIP 在 2337 上重训；AG 需要 CLIP 的 AG 特征。

## 5. 完整正向数据流

### 5.1 训练（A0/A2）

```
PKM sampler: P identities × K=4 tuples × 3 modalities
  → train_collate_fn
  → imgs = [RGB (B,3,256,128), NIR (B,3,256,128), TIR (B,3,256,128)]
  → target [B], camids [3×B]
  → model.forward(mode=0):
       x = cat(imgs, dim=0)              # [3B,3,256,128]
       f = ViT(x)                        # [3B,768] pre-BN CLS
       z = BNNeck(f)                     # [3B,768]
       s = classifier(z)                 # [3B,C]
  → CE(s, target_rep)
  → WRT(f, target_rep, camids_cat)       # raw Euclidean + optional camera mask
  → ProCA(f, target, M=3, K=4)           # modality centers → identity center
  → GPD(f, target, bank, tau=0.03)       # feature vs global prototypes
  → loss = CE + WRT + 0.01*ProCA + GPD
  → backward → clip 1.0 → SGD step
  → GPD bank EMA update (no grad)
  → EMA model update (no grad)
```

### 5.2 推理

```
single image (3,256,128)
  → ViT → pre-BN CLS f (768)
  → optional flip TTA: normalize(f)+normalize(flip(f))
  → evaluator L2 normalize
  → squared Euclidean / full gallery
  → exclude all gallery images with same camera id
  → CMC / mAP / mINP / nine pairs / AG
```

不加载 GPD bank、classifier、EMA（EMA 是另一份权重）。

## 6. 完整反向梯度流

| 损失 | 作用张量 | 梯度路径 | 不接收梯度的对象 |
|---|---|---|---|
| CE | `s = classifier(BNNeck(f))` | classifier → BNNeck → f → ViT | — |
| WRT | raw f（可混合归一化方向） | f → ViT | camera mask |
| ProCA | per-sample L2(f) → modality center → identity center | modality centers → f → ViT | identity center `g_cent`（detach） |
| GPD | L2(f) 与 L2(prototypes) | f → ViT | prototype bank（buffer） |
| GPD warm-start | 无 | 无（no_grad buffer 初始化） | 全部 |
| CA-WRT mask | 布尔掩码 | 无 | 掩码 |
| EMA / soup | 无 | 无（权重空间操作） | — |
| Flip TTA | 推理特征 | 无（推理） | — |

**关键边界**：
- ProCA 的 `g_cent` 是 stop-gradient anchor；只有模态中心及其图像特征接收梯度。
- GPD 的原型不接收梯度；bank 在 optimizer step 后 EMA 更新。
- CA-WRT 只改负样本权重，不改正样本；不新增参数。
- Finetune 加载的 classifier/BNNeck 与 backbone 一起接收梯度；不会从随机初始化开始。

## 7. 损失、归一化与参数顺序

### 7.1 原 UAD 顺序（不变）

1. ViT 输出最后一层 LayerNorm 后的 CLS `f`。
2. CE：`z = BNNeck(f)`；`s = classifier(z)`；交叉熵。
3. WRT：在 `f` 上计算欧氏距离；正/负 softmax 加权；SoftMarginLoss。
4. ProCA：对 `f` 逐样本 L2 → 每个 (PID, modality) K=4 均值 → 再 L2 → 三模态均值 → 再 L2 → `detach` 作为身份中心；损失是各模态中心到身份中心的平方距离均值。
5. GPD：对 `f` 逐样本 L2；对原型 L2；点积 / τ=0.03；交叉熵。
6. 推理：`f` → evaluator L2 → 平方欧氏。

### 7.1.1 四项损失的完整公式与作用范围

记一个 batch 有 `B` 个 tuple、`M=3` 个模态，拼接后 `N=3B` 张图；第 `i` 张图的 pre-BN CLS 为 `f_i∈R^768`，标签为 `y_i`，BNNeck 后特征 `z_i=BN(f_i)`。

**CE（系数 1.0，作用于 BNNeck 后）**

$$
\mathcal{L}_{CE}=-\frac{1}{N}\sum_{i=1}^{N}\log
\frac{\exp(W_{y_i}^\top z_i)}{\sum_{c=1}^{C}\exp(W_c^\top z_i)}
$$

- `W∈R^{C×768}` 是共享身份分类器，`C` 是训练身份数（1000 为 500，2337 为 1000）。
- 梯度：classifier → BNNeck → `f` → ViT。
- 推理不使用 `z`/classifier。

**WRT（系数 1.0，作用于 pre-BN `f`）**

$$
d_{ij}=\|f_i-f_j\|_2
$$

$$
w^{+}_{ij}=\frac{\exp(d_{ij})\cdot \mathbb{1}[y_i=y_j]}{\sum_{k}\exp(d_{ik})\cdot \mathbb{1}[y_i=y_k]},\quad
w^{-}_{ij}=\frac{\exp(-d_{ij})\cdot \mathbb{1}[y_i\neq y_j]}{\sum_{k}\exp(-d_{ik})\cdot \mathbb{1}[y_i\neq y_k]}
$$

$$
d_i^{+}=\sum_j w^{+}_{ij}d_{ij},\quad d_i^{-}=\sum_j w^{-}_{ij}d_{ij}
$$

$$
\mathcal{L}_{WRT}=\frac{1}{N}\sum_i \mathrm{SoftMargin}(d_i^{-}-d_i^{+};\,1)
=\frac{1}{N}\sum_i \log\left(1+\exp(-(d_i^{-}-d_i^{+}))\right)
$$

- 正样本权重强调“远正样本”；负样本权重强调“近负样本”。
- 默认对 `f` 的原始欧氏距离计算；`WRT_NORM_BETA=0`。
- CA-WRT 只改负样本权重：同相机负样本乘 `w_neg`（默认 0.25）；正样本不变。
- 梯度：`f` → ViT；camera mask 不接收梯度。

**ProCA（系数 0.01，作用于 pre-BN `f` 的 L2 中心）**

对身份 `y`、模态 `m` 的 `K=4` 个特征：

$$
\tilde f_{y,m,k}=\mathrm{L2}(f_{y,m,k}),\quad
\mu_{y,m}=\mathrm{L2}\left(\frac{1}{K}\sum_{k=1}^{K}\tilde f_{y,m,k}\right)
$$

$$
\mu_y=\mathrm{sg}\left[\mathrm{L2}\left(\frac{1}{M}\sum_{m=1}^{M}\mu_{y,m}\right)\right]
$$

$$
\mathcal{L}_{ProCA}=\frac{1}{P}\sum_{y=1}^{P}\frac{1}{M}\sum_{m=1}^{M}
\|\mu_{y,m}-\mu_y\|_2^2
$$

- `sg` 是 stop-gradient；身份中心 `μ_y` 不接收梯度。
- 梯度经每个模态中心及其图像特征回传；梯度不经过 `μ_y`。
- 顺序：逐样本 L2 → K 均值 → L2 → 三模态均值 → L2 → detach。

**GPD（系数 1.0，作用于 pre-BN `f` 与全局原型）**

$$
u_i=\mathrm{L2}(f_i),\quad p_c=\mathrm{L2}(P_c),\quad
\ell_i=-\log\frac{\exp(u_i^\top p_{y_i}/\tau)}
{\sum_{c=1}^{C}\exp(u_i^\top p_c/\tau)}
$$

$$
\mathcal{L}_{GPD}=\frac{1}{N}\sum_{i=1}^{N}\ell_i,\quad \tau=0.03
$$

- 原型 `P∈R^{C×768}` 是 buffer，不接收梯度。
- 每个 optimizer step 后：
  $$
  P_c\leftarrow \mathrm{L2}\left((1-m)P_c+m\,\mu_c\right),\quad m=0.2
  $$
  其中 `μ_c` 是当前 batch 该身份的模态中心；默认固定 `m=0.2`。
- 暖启动：`P_c` 初始化为训练集三模态类均值（L2），`counts=1`；之后按上式 EMA。
- 可选 `GPD_COUNT_EMA=True` 时，`m_eff=clamp(1/(count+1), min, max)`；默认关闭。
- 可选温度课程 `GPD_TAU_WARM>0`；默认关闭。

**总损失**

$$
\mathcal{L}=\mathcal{L}_{CE}+1.0\cdot\mathcal{L}_{WRT}
+0.01\cdot\mathcal{L}_{ProCA}+1.0\cdot\mathcal{L}_{GPD}
$$

本方案**不新增任何损失项**；只改 WRT 的负样本掩码、GPD 的 bank 初始化/可选 EMA/温度，以及训练 schedule/EMA/TTA。

### 7.1.2 Query 的定义与初始化

- **本方案不引入可学习 Query token。**
- 训练时，每个“query”就是当前图像本身：`f_i` 是输入图像的 pre-BN CLS；正/负样本是同一 batch 内其他图像。
- ProCA 的“中心”不是可学习 query，而是同一 `(PID, modality)` 的 K=4 个图像特征的 L2 均值。
- GPD 的“原型”不是可学习 query，而是每个训练身份的 EMA buffer。
- 推理时，query 是输入图像的 pre-BN CLS；gallery 是测试集图像特征；没有额外的 query 初始化或 query token。
- Plan B 融合不引入 query；只是把两个模型对同一图像的描述子做分数/特征融合。
- 可选 PMC 也不引入 query；只是 3 个分类头。

### 7.2 本方案改动的位置

| 组件 | 改动位置 | 是否改归一化顺序 |
|---|---|---|
| A0/A2 | optimizer/schedule | 否 |
| LLRD | optimizer 参数组 LR | 否 |
| EMA/soup | 权重空间 | 否 |
| GPD warm-start | bank 初始化 | 否（仍 L2 均值 → L2） |
| CA-WRT | WRT 负样本掩码 | 否（仍 raw Euclidean；可选 norm blend 默认 0） |
| Flip TTA | 推理特征平均 | 是（每支先 L2，再相加；evaluator 再 L2） |
| Plan B fusion | 推理后特征/分数 | 是（每模型先 L2，再融合） |

### 7.3 参数表（新增/改动）

| 参数 | 默认 | 含义 | 是否参与梯度 |
|---|---:|---|---|
| `MODEL.LLRD_DECAY` | 0.0 | ViT 分层 LR 衰减；0 关闭 | 否（只改 optimizer LR） |
| `MODEL.EMA` | False | 是否维护 EMA | 否（权重空间） |
| `MODEL.EMA_DECAY` | 0.999 | EMA 衰减 | 否 |

| `MODEL.WRT_NORM_BETA` | 0.0 | WRT 归一化方向混合；默认关闭，仅消融 | 是（若 >0） |

## 10. 预期、风险与争议

### 10.1 预期

| 组件 | 1000 AS 预期 | 说明 |
|---|---|---|
| A0 | mAP +0.2–0.6、R1 +0.4–1.2 | 尾段斜率外推；mAP 慢 |
| A2 | mAP +0.4–0.8、R1 +0.8–1.8 | 干净长 schedule |
| GPD 暖启动 | +0.1–0.3 | 主要避免 finetune 冷启动 |
| CA-WRT | +0.1–0.3 | 方向正确、幅度不确定 |
| EMA/soup | +0.1–0.4 | 稳定 |
| Flip TTA | +0.2–0.5 | 需四项都不降 |
| Plan B 融合 | mAP 12.4–13.0、R1 30.0–31.0 | 依赖错误互补 |

单模型合计现实区间：mAP +0.5–0.9、R1 +1.0–2.0；**mAP 仍可能差 0.1–0.5**。这是把 LHF 押在 R1/R10 上的必然结果。

### 10.2 风险

- **A0 过拟合/退化**：低 LR 延长不等于不会过拟合；看训练/测试 gap、GPD loss、危险负样本相似度。
- **CA-WRT 方向不确定**：同相机负样本也可能是最危险负样本；先统计。
- **GPD 暖启动偏 RGB**：三模态均值缓解；若 TIR 掉点，检查覆盖率与 GPD loss。
- **EMA/soup DDP eval**：EMA 必须在所有 rank 一致；训练期验证用 final，避免拼接两个模型。
- **GD R5/R10 零余量**：任何回退都要否决。
- **1pp 噪声**：单 seed 的 +1pp 可能是近 tie 翻转；必须 2 seed + bootstrap。
- **Plan B 双模型**：公平性与成本；2337/AG 未验证。

### 10.3 争议点

- 延长训练是否算“方法改进”？目标是对比论文数值，延长 schedule 是合法训练策略；报告中明确披露。
- TTA 是否改变协议？TTA 是推理增强，单独报告；主结果可给“无 TTA”和“有 TTA”两列。
- EMA/soup 是否算模型改进？属于训练/推理策略；预注册主结果。
- 双模型融合是否可接受？必须明确披露；若不可接受，只作为上限诊断。
