## 2. `model/make_model.py`：finetune 全量加载

### 2.1 原问题

- `build_transformer.__init__` 只处理 `pretrain_choice == 'imagenet'`。
- `load_param_finetune` 是死代码，且原实现假设 checkpoint 没有 `module.` 前缀、没有 wrapper。
- `load_param` 显式跳过 `classifier`；即使手动调用，classifier/BNNeck 也不会恢复。
- 因此 `PRETRAIN_CHOICE='finetune'` 会从随机权重或丢失分类器开始，A0 的所有结果不可解释。

### 2.2 修改

在 `classifier` 与 `bottleneck` 创建之后：

```python
if pretrain_choice == 'finetune':
    self.load_param_finetune(model_path)
```

`load_param_finetune` 的新实现：

```python
def load_param_finetune(self, model_path):
    try:
        param_dict = torch.load(model_path, map_location='cpu', weights_only=False)
    except TypeError:
        param_dict = torch.load(model_path, map_location='cpu')
    if 'state_dict' in param_dict:
        param_dict = param_dict['state_dict']
    if 'model' in param_dict:
        param_dict = param_dict['model']

    own = self.state_dict()
    loaded, skipped = 0, []
    for key, value in param_dict.items():
        key = key.replace('module.', '')
        if key not in own:
            skipped.append((key, 'missing_in_model')); continue
        if own[key].shape != value.shape:
            skipped.append((key, 'shape_mismatch')); continue
        own[key].copy_(value)
        loaded += 1
    print('Finetune checkpoint: loaded {} tensors, skipped {}'.format(loaded, len(skipped)))
```

要点：
- 顺序：先建 backbone，再建 classifier/bottleneck，最后加载完整 state dict。
- 支持 `state_dict` / `model` wrapper、`module.` 前缀、shape 不匹配跳过。
- `state_dict()` 返回参数引用，`copy_` 原地写入；不会破坏 optimizer 之后绑定。
- 自检：`tools/check_checkpoint_load.py`。

### 2.3 自检结果（本地 CPU）

## 3. `solver/make_optimizer.py`：LLRD

### 3.1 修改

```python
def _llrd_scale(key, decay):
    if decay <= 0: return 1.0
    m = re.match(r'^base\.blocks\.(\d+)\.', key)
    if m:
        return decay ** (11 - int(m.group(1)))
    if key.startswith('base.patch_embed'):
        return decay ** 12
    if key in ('base.cls_token', 'base.pos_embed'):
        return 0.1
    if key.startswith('base.norm'):
        return 0.5
    return 1.0

lr = cfg.SOLVER.BASE_LR * _llrd_scale(key, decay)
if "bias" in key:
    lr = lr * cfg.SOLVER.BIAS_LR_FACTOR
```

要点：
- 只改 optimizer 的 group LR；前向/反向不变。
- `decay=0` 时 `lr=BASE_LR`，与原实现一致。
- bias 先乘 LLRD，再乘 `BIAS_LR_FACTOR`；与原实现“bias=base*2”在 `decay=0` 时一致。
- `LARGE_FC_LR` 仍覆盖 classifier/arcface 为 `base*2`。
- 红队建议：LLRD 只在 A2 用，`decay=0.85–0.9`；A0 不用。
- 注意全局 cosine floor：`decay=0.5` 时低层 LR 可能低于 `lr_min`，scheduler 会反向抬升；0.85–0.9 不会。

### 3.2 自检

本地 smoke test：154 个 param groups，min/max LR 正常，无异常。

## 4. `solver/scheduler_factory.py` + `solver/constant_lr.py`

### 4.1 Cosine floor

原：

```python
lr_min = 0.002 * cfg.SOLVER.BASE_LR
```

改：

```python
lr_min = cfg.SOLVER.LR_MIN_FACTOR * cfg.SOLVER.BASE_LR
```

用途：
- 原 UAD：`LR_MIN_FACTOR=0.002`，行为不变。
- A2：`LR_MIN_FACTOR=0.002`。
- A0：使用 constant scheduler，不依赖 cosine floor。

### 4.2 ConstantLRScheduler（A0）

新增 `solver/constant_lr.py`：

```python
class ConstantLRScheduler:
    def __init__(self, optimizer, lr):
        self.optimizer = optimizer
        self.lr = float(lr)
        self._set()
    def _set(self):
        for group in self.optimizer.param_groups:
            group['lr'] = self.lr
    def step(self, epoch=None):
        self._set()
    def _get_lr(self, epoch=None):
        return [self.lr for _ in self.optimizer.param_groups]
```

`scheduler_factory.create_scheduler`：

```python
if getattr(cfg.SOLVER, 'SCHEDULER', 'cosine') == 'constant':
    return ConstantLRScheduler(optimizer, cfg.SOLVER.BASE_LR)
```

要点：
- A0 的 **所有参数组（含 bias）** 固定为 `BASE_LR=6.4e-5`，严格等于基线终段 LR。
- 如果只用 `LR_MIN_FACTOR=1.0` 的 cosine，bias 组会从 `2×BASE_LR` 衰减到 `BASE_LR`，不是真正恒定；constant scheduler 解决了这一点。
- `SCHEDULER='cosine'` 是默认，原 UAD/A2 行为不变。

## 5. `utils/ema.py`：ModelEma

新增：

```python
class ModelEma:
    def __init__(self, model, decay=0.999):
        self.module = copy.deepcopy(model).eval()
        for p in self.module.parameters(): p.requires_grad_(False)
        self.decay = float(decay)

    @torch.no_grad()
    def update(self, model):
        d = self.decay
        ema_state = self.module.state_dict()
        model_state = model.state_dict()
        for key, ema_v in ema_state.items():
            v = model_state[key].detach()
            if ema_v.dtype.is_floating_point:
                ema_v.mul_(d).add_(v, alpha=1.0 - d)
            else:
                ema_v.copy_(v)

    def state_dict(self):
        return self.module.state_dict()
```

要点：
- 浮点张量 EMA；整数 buffer（如 `num_batches_tracked`）直接复制。
- `copy.deepcopy(model).eval()` 保证 EMA 副本不参与训练、BN 用 running stats。
- 所有 rank 各自维护同一份 EMA；保存只在 rank 0。
- EMA 是完整 state dict，键与训练模型一致，可直接用 `test.py` 的 `TEST.WEIGHT` 加载（`load_param` 会跳过 classifier，但 EMA 的检索特征不需要 classifier）。

### 6.2 `warm_start_prototypes`

新增函数：

```python
@torch.no_grad()
def warm_start_prototypes(model, bank, loaders, device, logger=None):
    model.eval()
    sums = torch.zeros(bank.num_classes, bank.feat_dim, device=device)
    cnts = torch.zeros(bank.num_classes, device=device)
    for mode, loader in enumerate(loaders, start=1):
        for batch in loader:
            img = batch[0].to(device)
            pid = torch.as_tensor(batch[1], dtype=torch.long, device=device)
            feat = model(img, mode=mode)
            feat = F.normalize(feat.float(), dim=1)
            sums.index_add_(0, pid, feat)
            cnts.index_add_(0, pid, torch.ones_like(pid, dtype=cnts.dtype))
    mask = cnts > 0
    centers = torch.zeros_like(sums)
    centers[mask] = F.normalize(sums[mask] / cnts[mask].unsqueeze(1), dim=1)
    bank.initialize(centers, counts=1.0)
    model.train()
```

要点：
- 三模态遍历；每张图 pre-BN CLS → L2 → 按 PID 累加 → 均值 → 再 L2。
- `counts=1`；`GPD_COUNT_EMA` 首次更新不会被 `m_eff=1` 覆盖。
- no_grad；不更新模型、不更新 BN、不进入计算图。
- 使用确定性 `train_normal_loaders`（无随机增强）。
- `model.eval()` 用 running stats；结束时 `model.train()`。

`do_train` 中：

```python
if use_aux_modules and cfg.MODEL.GPD_WARMSTART:
    if dist_on:
        if is_main:
            warm_start_prototypes(model_meta, proto_bank, train_normal_loaders, device, logger)
        dist.barrier()
        dist.broadcast(proto_bank.prototypes, src=0)
        dist.broadcast(proto_bank.counts, src=0)
    else:
        warm_start_prototypes(model_meta, proto_bank, train_normal_loaders, device, logger)
```

要点：
- rank 0 计算；所有 rank barrier + broadcast，保证 bank 一致。
- 非 rank 0 不执行前向，避免重复计算。
- 若 `train_normal_loaders` 为空，函数返回 0，broadcast 零 bank；不会崩溃。

### 7.1 构造

### 7.2 forward

```python
def forward(self, inputs, targets, normalize_feature=False,
            camids=None, norm_beta=0.0):
    if normalize_feature:
        inputs = normalize(inputs, axis=-1)
    if norm_beta > 0:
        unit = normalize(inputs, axis=-1)
        scale = inputs.norm(dim=1, keepdim=True).mean().detach()
        inputs = (1 - norm_beta) * inputs + norm_beta * (unit * scale)
    dist_mat = pdist_torch(inputs, inputs)
    ...
    pos_mask = is_pos
    neg_mask = is_neg
    if self.use_camera and camids is not None:
        same_cam = camids.reshape(-1, 1).eq(camids.reshape(1, -1)).float()
        neg_mask = is_neg * (1.0 - same_cam) + is_neg * same_cam * self.cam_neg_weight
        empty = neg_mask.sum(dim=1) <= 0
        if empty.any():
            neg_mask[empty] = is_neg[empty]
    dist_ap = dist_mat * pos_mask
    dist_an = dist_mat * neg_mask
    weights_ap = softmax_weights(dist_ap, pos_mask)
    weights_an = softmax_weights(-dist_an, neg_mask)
```

要点：
- **正样本不变**；只压同相机负样本。红队指出同相机正样本包含跨模态正样本，不能降权。
- 默认 `use_camera=False`、`norm_beta=0`，与原 WRT 完全一致（包括对角线自匹配行为）。
- `same_cam` 是布尔/float 掩码，不接收梯度。
- 若某行负样本全被压到 0，回退到原 `is_neg`，避免 NaN/零梯度。
- `norm_beta` 是可选单变量消融；默认 0，不作为主方案。混合公式保持原特征尺度：`unit*scale`，`scale` detach。

triplet = TripletLoss_WRT(
    use_camera=cfg.MODEL.WRT_CAMERA,
    cam_neg_weight=cfg.MODEL.WRT_CAM_NEG_WEIGHT,
)
...
def loss_func(score, feat, target, camids=None, epoch=0):
    ...

    TRI_LOSS = triplet(feat, target, camids=camids, norm_beta=beta)[0]

## 12. 正向/反向路径核对

### 12.1 训练

```
imgs [RGB;NIR;TIR] → ViT → f (pre-BN, 768)
  ├─ BNNeck(f)=z → classifier → CE
  ├─ WRT(f, target_rep, camids_cat) → CE? no, SoftMarginLoss
  ├─ ProCA(f) → 0.01 * center loss
  └─ GPD(f, bank, tau) → prototype CE
loss = CE + WRT + 0.01*ProCA + GPD
backward → clip 1.0 → SGD step
→ GPD bank EMA (no grad)
→ EMA model update (no grad)
```

### 12.2 推理

```
img → ViT → f (pre-BN, 768)
→ optional flip: normalize(f)+normalize(f_flip)
→ evaluator L2
→ squared Euclidean, full gallery, exclude same camera
→ CMC/mAP/mINP/九组合/AG
```

### 12.3 梯度边界

| 项 | 梯度 |
|---|---|
| CE | classifier → BNNeck → f → ViT |
| WRT | f → ViT |
| ProCA | modality centers → f → ViT；identity center detach |
| GPD | f → ViT；bank buffer no grad |
| GPD warm-start | no grad |
| CA-WRT mask | no grad |
| EMA/soup | no grad |
| TTA | 推理，无梯度 |

## 13. 归一化顺序

| 路径 | 顺序 |
|---|---|
| CE | ViT → BNNeck → classifier → CE |
| WRT | ViT f（raw）→ pdist；可选 norm_beta 混合方向；camera 负样本掩码；softmax 权重；SoftMargin |
| ProCA | f → 逐样本 L2 → 模态内 K 均值 → L2 → 三模态均值 → L2 → detach 身份中心 |
| GPD | f → L2；prototype → L2；点积/τ；CE |
| GPD 暖启动 | f → L2 → PID 均值 → L2 |
| 推理 | f → TTA 每支 L2 → 相加 → evaluator L2 |
| 融合 | 每模型 L2 → 分数/特征融合 → 评测 |

**没有改变原 UAD 的任何顺序**；TTA/fusion 只在评测端新增。

### 13.1 Query 的定义、初始化与特征来龙去脉

- **没有可学习的 ReID Query token。** ViT 只有 1 个 `cls_token`（`nn.Parameter`，由 ImageNet checkpoint 加载/随机初始化），它 prepend 到 128 个 patch token 前；最终取最后一层 LayerNorm 后的 `x[:,0]` 作为 pre-BN CLS `f`。
- **训练 query**：当前 batch 的每张图本身就是 query；`f_i` 是它的 pre-BN CLS。正/负样本是同一 batch 内其他图像；没有额外的 query 初始化。
- **ProCA 的中心**：同一 `(PID, modality)` 的 K=4 个图像特征经“逐样本 L2 → 均值 → L2”得到；不是可学习 query。
- **GPD 的原型**：每个训练身份一行 buffer；暖启动时由三模态训练集类均值初始化；不是可学习 query。
- **推理 query**：输入图像的 pre-BN CLS；gallery 是测试集图像特征；没有 query token、没有 bank、没有 classifier。
- **Plan B 融合**：UAD 与 CLIP 对同一图像各自产生一个描述子；融合在描述子/分数层进行，不引入 query 初始化。
- **可选 PMC（未落地）**：只是 3 个分类头；不引入 query。
